# Sessions de profilage

Le parcours pose des questions adaptatives sur expérience, connaissances, objectifs, horizon, capacité financière et tolérance au risque. Le LLM extrait du JSON validé ; une réponse manquante ou ambiguë déclenche une question de clarification. Les messages sont diffusés en SSE. Un profil structuré et un export PDF simple sont produits à la fin. Dans le prototype, les réponses sont conservées en mémoire pour la session et une suppression explicite est disponible. Aucune donnée personnelle réelle ne doit être utilisée.
