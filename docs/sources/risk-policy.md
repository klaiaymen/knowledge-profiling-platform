# Politique de risque du prototype

Ce dépôt présente un prototype pédagogique de profilage d'investisseur. Il ne constitue ni un conseil financier ni une validation réglementaire MiFID II. Le score est obtenu uniquement par une grille déterministe documentée dans `docs/profiling/risk-scoring.md`. Le LLM conduit l'entretien et extrait les réponses structurées ; il ne choisit ni ne calcule le score. Les catégories sont Prudent (0–34), Équilibré (35–69) et Dynamique (70–100).

Une réponse manquante ou ambiguë provoque une question de suivi. Le profil n'est disponible qu'une fois les six critères renseignés. Les données de démonstration sont synthétiques.
